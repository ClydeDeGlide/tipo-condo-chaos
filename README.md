# Tipo's Condo Chaos

A special edition of the side-scrolling arcade game starring Tipo, based on the supplied Yorkiepoo photograph.

## Play

Open `index.html` in a modern browser. No installation or server is required.

- A / D or arrow keys: move
- W / Up / Space: jump
- J: bark — a longer-range sound-wave attack
- K: bite — a stronger close-range lunge
- L: downward-dog chi — a wide-area special move
- P: pause

On iPhone and iPad, play in landscape orientation. On-screen buttons provide movement, jump, bark, bite, chi, and audio controls. Audio begins after the first tap, as required by mobile Safari.

Battle waves of Lamb Chop-style plush toys across a horizontally scrolling upscale beach condo. Reach the end of each ten-screen level and defeat the giant plush boss to continue.

The latest update gives Tipo a clearly forward-facing ready stance and a unique airborne pose. Plush enemies now stop farther away, hold attack poses longer, and use extended slap, kick, and magic ranges so their animations remain visible during combat.

This version further extends bite range, adds synthesized bark/growl/howl effects, and includes an original looping arcade soundtrack generated in the browser.
